# VSCode 手册素材

使用手册里的 `📷` / `🎬` 占位块对应下表中的文件。拍好后放到本目录，
在 `docs/USER-GUIDE.md` 里把占位块替换成 `![说明](images/vscode/文件名)` 即可。

| 文件 | 类型 | 建议内容 |
|---|---|---|
| `01-install.png` | 截图 | 扩展市场搜索 `4gl-full` 的安装页 |
| `02-first-open.png` | 截图 | 打开项目后的 Problems / 状态栏 |
| `03-hover.gif` | 录屏 | 悬停变量显示来源与定义位置 |
| `04-completion.gif` | 录屏 | 输入 `DISPLAY` 后的补全 |
| `05-format.gif` | 录屏 | 格式化前后对比 |
| `06-field-fix.png` | 截图 | 字段不存在的波浪线与 Quick Fix |
| `07-link-view.png` | 截图 | 侧边栏“链接资料”树 |
| `08-link-reverse.gif` | 录屏 | 反查引用程序并跳到 `.4gl` |
| `09-deploy.png` | 截图 | 部署命令与输出面板 |
| `10-settings.png` | 截图 | 设置页筛选 `@ext:4gl-full` |

素材要求：
- 截图宽度 1200–1600 px，深色/浅色主题都可以，保持同一份文档内一致；
- 录屏 10 秒以内，只保留关键操作，转成 GIF 或 MP4（MP4 请同时说明文件名）；
- 不要包含真实主机名、账号、密码、客户代码；必要时打码。
